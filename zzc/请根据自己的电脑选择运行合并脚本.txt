xmjd6 zzc 目录说明

普通用户只需要按自己的电脑系统运行对应脚本。

Windows:
- Windows_词库合并.py（推荐使用 Pixi Python，调用当前可审查的合并核心）
- Windows_撤回合并.py
- Win_词库合并.exe
- Win_撤回合并.exe
- 不安装 Python 时可双击 exe；维护者和 Pixi 用户优先使用 Python 入口。

Mac:
- Mac_词库合并
- Mac_撤回合并
- 交给有 Mac 环境的人打包成无扩展可执行文件后使用。

Linux:
- Linux_词库合并.py
- Linux_撤回合并.py
- 需要电脑已安装 Python 3。

iOS:
- iOS_词库合并.py
- 免费方案使用 a-Shell，Pythonista 也可以运行。
- 把 Mac_词库合并 放在同目录或所选方案目录的 zzc/ 目录。
- 首次运行选择最终方案目录；zzc_state 默认放在该目录下，不要分到两个同步位置。
- 详细步骤见 a-Shell快捷指令合并说明.md 或 iOS快捷指令合并说明.md。

重要文件:
- ../xmjd6.zzc.dict.yaml
  自造词操作记录，也是临时 zzc 码表。
- ../zzc_state/zzc_reset.tsv
  电脑合并后写入的清理标记，用于手机识别并重置已合并的本地 zzc。
- ../zzc_state/zzc_reset_seen.tsv
  手机侧已处理 reset marker 的记录。
- ../zzc_state/char_parts.tsv
  单字拆分索引，合并脚本会自动重建。
- ../zzc_state/runtime_ops.tsv / runtime_exact.tsv / effective_state.tsv / runtime_ops_appended.tsv / cache_version.tsv
  输入法运行态数据，合并或重置后按规则清理或重建。
- 撤回合并/
  合并前自动备份目录，只保留最近 3 份。

撤回合并:
- 每次合并前，脚本会备份正式码表和 zzc 文件。
- 需要反悔时，运行对应平台的撤回合并工具。
- 撤回脚本会显示最近 3 份备份，手动选择恢复哪一份。
- 撤回是整文件恢复，不做复杂 diff。
